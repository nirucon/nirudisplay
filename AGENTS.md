# Contributor instructions

- This component is part of the NIRUX desktop. Follow the suite's minimal,
  keyboard-first X11 style and use the shared theme, font and `niructl` backend.
- Never move a published tag or replace an immutable release asset. Publish a
  new version for corrections.
- Keep host identities, credentials and private planning material out of
  source, fixtures, commits, screenshots and release notes.
- Test on real authorized hardware; container or VM output is not acceptance.
- Report actual evidence and limitations. A successful build or parsed profile
  is not proof of a working display transaction.
